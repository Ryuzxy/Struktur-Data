RBT Visualizer Tutorial
1
Understanding Nodes

Red-Black Tree nodes have two colors: Red and Black. Each node contains a key (timestamp) and reservation data.

2
RBT Properties

1. Every node is either red or black
2. The root is always black
3. Red nodes cannot have red children
4. Every path from root to leaf has same number of black nodes

3
Tree Operations

Use the operation panel to insert, search, or delete nodes. The tree will automatically rebalance to maintain RBT properties.

4
Visual Controls

Use zoom controls, change layout, and adjust display options to better understand the tree structure.

5
Performance Metrics

Monitor performance metrics to see how RBT maintains O(log n) operations even with many nodes.
